# Model weights

This directory stores main-dataset `.pt` checkpoints. Training histories now live
in `artifacts/main/training/`; metrics in `artifacts/main/evaluation/`.
Benchmark weights stay in `benchmarks/<name>/checkpoints/`.

Existing model filenames are unchanged. For old `history_file` references inside
checkpoints, see the [migration guide](../docs/repository_layout.md#historical-paths-and-integrity).
